# 方案内嵌菜单原型｜评审版

> 历史说明：本稿记录目录演示版。v4 已加入可切换的现状和调整后界面及五个设置落点，实际范围见 [v4 复刻规范](SOLVEA-REPLICA.md)，可在[方案中体验](../solution.html#prototype)。

用途：验证管理员能否按配置用途找到入口；属于可操作的导航评审，不是现网 UI 复刻。正式后台的视觉基座、逐页参考和高保真规范仍由 PUBLIC-SPEC 确认。

| 入口 | 可达状态 | 触发 |
|---|---|---|
| 方案「点原型看变化」 | `#home` | 嵌入原型默认显示设置中心及三类入口 |
| 方案演示按钮、开发对照表 | `#<分类>/<设置项>` | 滚至内嵌原型并直接选中对应设置项；提供同状态独立打开链接 |
| 设置中心首页与侧栏 | `#common`、`#ai`、`#ticket` | 进入各分类并列出分组和设置项 |
| 分类设置项 | `#<当前分类>/<设置项>` | 高亮设置项并显示其所在分组；设置项注册以 `prototype/menu.js` 为准 |
| 侧栏「设置中心」 | `#home` | 返回原型首页 |
| 独立打开版「返回方案」 | `solution.html#prototype` | 返回方案的嵌入位置 |

无搜索、权限切换、表单保存或旧生产 URL 跳转。旧入口只出现在方案对照中；未知兼容方式、暂不合并和不迁入条目仍标在对照与 I01–I12 中。每个有演示落点的迁移条目只演示目录归属。验收：三类可到达，代表条目可直达、可刷新重入，选中项与旧新对照一致，独立版可返回方案。
