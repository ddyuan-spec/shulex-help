# 统一设置中心：关联影响逐项确认表

本表是开发进入实现前的确认清单。除 I01、I07、I08、I09、I10 的“导航归属”外，其他条目不因一期菜单调整自动完成。

| ID | 影响项 | 一期建议 | 需要确认的结论 |
|---|---|---|---|
| I01 | 旧菜单与深链 | 保留旧链接可达或解释性跳转。 | 兼容期、跳转方式、返回上下文。 |
| I02 | 角色与权限 | 只迁成员/团队/角色的管理入口。 | 设置中心权限继承；R19 邮箱隔离不受影响。 |
| I03 | 字段、变量与展示 | 分开管理定义、AI 提取、工单展示。 | 是否统一字段目录与引用模型。 |
| I04 | 标签类型与引用 | 本期不做数据合并。 | 周五 R44 单独确认客户/工单/AI 标签关系。 |
| I05 | 模板治理 | 集中发现入口，保留来源和用途。 | 公共/个人层级、跨项目可见性、渠道审核。 |
| I06 | 渠道账号与外部集成 | 统一连接目录，业务/客户专属配置留原场景。 | 渠道、工具、API、Webhook 的配置边界。 |
| I07 | 分配与接待 | 归入工单设置，不改运行机制。 | 与路由中心的最终入口关系。 |
| I08 | 自动化、触发器及 Webhook | 分单、工单处理、留言邮箱、触发器是各自配置页；Webhook 单独管理端点，触发器只引用。 | 核对两条分单旧路径、各页权限与灰度、触发顺序、端点 ID 和启停；通用导航是否仍沿用原工单权限。见[逐项核查](spec/settings-audit.md)。 |
| I09 | 满意度调查 | 归入服务标准，不合并发送开关。 | 沿用 V131-02 独立范围。 |
| I10 | AI 安全、质检与脱敏 | 留在智能客服设置。 | 是否保持“AI 安全”命名与质检入口层级。 |
| I11 | 知识与帮助中心 | 不迁入设置中心。 | 帮助中心实际归属与后续规划。 |
| I12 | 报表与日常业务操作 | 留数据分析和原业务模块。 | 需要哪些上下文跳转，不新增重复编辑。 |
