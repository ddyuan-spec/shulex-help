# 开放平台｜页面规格（待评审）

## 复刻基线和变更清单


| 页 | A 类：现有基线 | B 类：本轮拟新增 |
|---|---|---|
| `integration` | 智能客服「集成」下的开放平台应用配置入口 | 无 |
| `open-app` | 顶部「返回」「开放平台」「导出应用接入文档」和 API 文档入口；步骤「创建开放平台应用」（应用名称、创建应用并签发凭据、应用凭据 `client_id` / `client_secret`）、「配置工作域权限」（工单域、Agent 域、知识库域、保存并授权/保存更改）、「配置第三方用户映射」、「Webhook 配置」 | 在「配置工作域权限」的工单域下方加「工单个人信息读取」申请入口及申请/授权状态，显示当前获批字段；沿用同一个应用配置页 |
| `open-apply` | 沿用集成既有编辑表单控件 | 本工作空间与应用只读，选择所需字段，填写使用目的；提交或取消 |
| `open-doc` | 现有工单列表/详情/消息 API 路径与响应结构 | 用相同示例对照无授权、仅批准邮箱、授权撤销；Webhook 与投递记录边界放批注 |

## 角色与流程

有现有集成配置权限的应用接入负责人发起申请；外部开发者使用已授权应用的服务端凭据调用；平台复核方处理申请，前端只回显审核结果。保留现有当前工作空间授权；本轮不新增租户角色配置、第三方开发者注册、跨租户授权、自助审核或审批中心。

1. **未创建应用**：保留原创建入口；创建与工单工作域开通后，申请入口可用。已有应用直接进入，不重新注册。
2. **申请**：当前应用和工作空间由登录上下文带入，不允许手输他租户。字段建议先列代码已有客户姓名、邮箱，电话若未确认对外接口已有则不列进首批 API。申请正文、附件或全量导出不搭车。勾选至少一项并填写使用目的才能提交，失败保留输入，取消不改变授权。
3. **回显**：未申请、审核中、已授权、未通过、已撤销。审核中仍沿用已生效授权，初次申请中不得返回原文。未通过展示原因，可调整重提；扩权需重新申请，既有获批字段不因新增申请自动扩大。
4. **运行与撤销**：建议按应用 × 工作空间 × 工单工作域 × 已获批字段判定，每次请求读取当前状态。无授权字段按接口兼容方案返回遮盖值，原接口权限失败仍按原鉴权返回。授权撤销后下一次调用即失效，旧令牌不兜底；不能回收第三方已收到的副本。

示例应用「售后对账」，只申请客户邮箱核对退换货记录。未获批或撤销时 `a***@example.com`；批准后 `amy@example.com`；没有同时批准姓名的情况下姓名仍遮盖。示例用于产品评审，不连接真实租户或 API，具体返回字段名以已发布接口 schema 为准。

## 八项验收

| 项目 | 交互稿检查 |
|---|---|
| 布局 | 逐屏对照真实集成/应用参考；只有未核验区域允许用明确标注的拟稿 |
| 视觉 | 继承对应页面控件、主题、排版和标签 |
| 表达 | 延用现有业务外壳，申请与状态靠业务组件表达 |
| 文案 | 区分应用、工作域、个人信息权限及令牌，使用实际原字段文案 |
| 导航 | 集成进入应用；应用进入申请和文档；提交、取消及返回落点正确 |
| 状态 | 未创建、未申请、待审、批准、拒绝、撤销可按独立场景验收 |
| 交互 | 必填校验、提交待审、拒绝重提、字段示例差异和撤销结果正确 |
| 引用 | 页面 ID、图标、合成数据和批注锚点完整；无实际凭据 |
