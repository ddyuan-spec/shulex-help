# Shulex Home / Solvea 帮助中心与自学习原型

在线原型：https://ddyuan-spec.github.io/shulex-help/ 。包含 Help Center、工单工作台、自学习页及功能批注。线上是静态交互演示，数据只保存在各访问者的浏览器中；不连接真实工单系统。

公开仓库只发布运行文件、虚构样例、功能批注与隔离测试。真实系统截图、历史评审截图、生成工具及系统核验记录留在本地；下文提及的「系统自学习逻辑核验.md」为本地记录。

运行 node serve.cjs，访问 http://127.0.0.1:4387/ 。全部业务写入仅在当前浏览器本地，不写入真实系统。

## 页面

- index.html：用户提问，AI摘要、已有FAQ、多类型来源预览、反馈、提交工单、LiveChat演示。依据不足不生成答案，无FAQ就隐藏，不推荐追问。
- workspace.html：按现有截图复刻工单；接手、分配、回复、解决、重开、内部备注及AI助手入口。
- self-learning.html：按实际自学习页补齐话题列表/设置、自动加入知识库、报告。只用「未添加/已添加」状态，不建立独立审核发布角色。
- faq.html：公开的本地知识库FAQ正文，不展示来源工单与客户资料。

## 现有逻辑与演示闭环

已实测系统设置：缺知识的人工回复每天自动学习；历史对话是单次学习。自动加入开关目前关闭；开启可将缺知识转人工学习的话题自动入库，历史学习内容仍需人工校验。报告阶段：数据源 → 话题 → FAQ → 使用。详细依据见「系统自学习逻辑核验.md」。

演示：顶部「自学习 · 知识中心」→「学习演示」→载入闭环示例→模拟每日学习→话题出现。开关关闭时保持未添加，不参与Help Center检索；查看/编辑后核对隐私并加入知识库，再用同一问题搜索。开关开启后，下次模拟任务可自动添加本地缺知识话题。重复运行不重复生成同问题话题。

也可以自己在Help Center输入未知问题、提交工单，由坐席回复后再运行模拟每日学习；工单AI助手可查看本地状态并进入关联话题。真实每日调度不会在原型中执行，任务按钮位于评审区，不是生产业务新增的人工触发要求。

## 客户权限与功能批注

客户成功页只有编号、状态、邮件说明和完成，完成后仍在Help Center。顶部明确为「评审导航 · 非客户功能」，不代表客户有后台权限。

「显示批注」打开字段编号，点击查看触发、效果/跳转及边界；「批注清单」查看本页规则。已确认需求包括本轮系统实测规则；本地演示和待确认项分别标识。全部文字同步于「功能批注.md」。

## 模拟边界

- 新渠道进入现有采集范围、每日具体时点、质量阈值、结束工单条件和索引时延尚未验证。
- 真实列表当前为空，话题详情/编辑/加入的界面为本次衔接设计，已在页面及批注说明。
- 本地按缺知识场景和人工回复筛选，提取文本、基础脱敏并按标准问题去重；不是AI语义聚类或质量评估。
- 本地加入前做基本隐私检查；正式复用现有系统完整鉴权、隐私过滤及知识处理链路。
- 检索只用已添加FAQ的标准问题精确匹配；旧版自建知识审核数据不参与检索。
- 真实系统只读核验，不修改staging开关、文件和数据；原型附件只保存元信息，邮件/聊天不真实发送。

## 多租户隔离（用户确认要求，生产待验收）

每个页面评审区展示 tenantId / knowledgeBaseId（对应接口 tenant_id / knowledge_base_id）；点击可查看隔离规则，所有字段批注补充归属与边界。新增第37条租户隔离要求、第38条服务端验收项。

演示固定绑定 tenant-shulex-home / kb-shulex-home-help。工单及问答快照、引用、附件元信息、消息、话题、FAQ、学习任务结果、自动入库设置、反馈及统计按租户和知识库分别保存/校验。复用链接若携带不同归属会阻止打开。旧的无租户本地演示数据保留但不读取，不自动认领或迁移。

服务端必须从可信站点/会话解析租户，验证站点绑定与知识库读写权限；不能信任URL、请求体或客户端演示配置作为身份。召回前过滤范围，来源预览/原文件/签名URL单独鉴权，缓存/索引/异步任务/导入/聚类去重/日志/统计保持同一归属。无上下文、错租户、未绑定知识库时拒绝；空召回不跨库兜底。

本地静态 assets 是公开虚构样例，不是受保护文件服务；本次未测试生产向量库、文件权限或后端鉴权。正式 Help Center 多知识库绑定、工单队列与学习目标映射、坐席授权和切换上下文需后端核对，见第38条批注。

验证：运行 node review/tenant-isolation.test.cjs，在内存中验证A/B租户同问题不同答案、同ID工单隔离、设置/任务/报表隔离、同租户其他知识库、参数篡改与无归属旧数据。该测试只验证演示逻辑。
